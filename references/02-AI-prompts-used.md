# AI Prompts Used 

## The following is a list of examples of the AI prompts I have used throughout my project

- Can you help me change some wordings in my business problem statement so it sounds more academic ?
- Do you think I have missed any major actors/stakeholders in my proposed list?
- Can you format this from regular text to a markdown table format please
- Do you think this functional requirement is atomic ?
- Do you think this functional requirement should be considered a should or could in the context of MoSCoW priority, I'm not sure, can you explain the difference too
